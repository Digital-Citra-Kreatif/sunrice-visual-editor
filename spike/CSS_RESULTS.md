# Round-trip test results: stylesheets

Generated by `php spike/css.php` on PHP 8.3.6, with what chromium 141.0.7390.37 said to `node spike/css-browser.mjs`.

The question: can a rule be found in a stylesheet, and one declaration of it changed, with nothing else in the file touched? `Sunrice\VisualEditor\Css\Stylesheet` reads a file for where its rules and declarations are, and makes each change as a cut into the text at one of those places. "In place" counts the rules and declarations found exactly where they are said to be. Each change is checked byte for byte: only the value, only the declaration (with its line, when it had one to itself), only the piece put in.
